# Project Overview

## Purpose

This repository brings together personal web design work and frontend experiments. The pages use plain HTML and CSS, with local image assets.

## Main experiences

- **Login interface:** a glass-style card, form fields, social-provider presentation, modal styling, and small motion effects.
- **Portfolio:** a page for presenting selected creative work.
- **Supporting pages:** additional screens and a storage-themed interface experiment.

## Technology

- HTML
- CSS
- Browser-native JavaScript where included in the individual pages
- Local PNG and JPG assets

There is no package manager or compilation pipeline required by the current static-page setup.

## Scope boundaries

The visual presence of a login form or social button should not be confused with a production authentication service. A production release would need a trusted backend, secure session handling, input validation, and a properly configured identity provider.
