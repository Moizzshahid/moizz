This is a quick guide to the top-level files.

| Path | Description |
| --- | --- |
| `index.html` | Main login-style page |

| `portfolio1.jpg`–`portfolio6.jpg` | Portfolio preview images |

## Maintenance tips

- Use relative paths for assets stored in this repository.
- Preserve exact filename casing; it matters on many hosting platforms.
- Before removing an image, search all HTML files for references to it.
- Keep documentation links relative so the repository remains portable.
