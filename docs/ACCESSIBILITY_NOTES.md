# Accessibility Notes

These notes are a practical review guide for the static interfaces in this repository.

## Keyboard use

- Keep interactive controls reachable with the Tab key.
- Preserve a visible focus indicator.
- Use buttons for actions and links for navigation.
- Avoid relying on hover as the only way to reveal information.

## Forms

- Give every input a persistent, programmatically associated label.
- Use the correct input type where appropriate.
- Make validation feedback clear in text, not color alone.
- Ensure error messages are announced when the interface updates.

## Visual presentation

- Check text contrast against translucent backgrounds.
- Respect reduced-motion preferences for non-essential animation.
- Provide useful alternative text for meaningful images.
- Treat decorative images as decorative so screen readers can skip them.

These are review recommendations, not a claim that every item has already been implemented.
