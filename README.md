# Moizz — Personal Web Projects

A collection of personal web pages and UI experiments, including a glassmorphism login experience, portfolio pages, and supporting screens.

## Project pages

| File | Purpose |
| --- | --- |
| `index.html` | Main login-style landing page |
| `next.html` | Supporting page in the login flow |
| `portfolio.html` | Portfolio presentation |
| `storage.html` | Storage interface experiment |

## Assets

The repository includes local image assets for branding, backgrounds, social sign-in buttons, and portfolio previews. Keep asset filenames and their references in HTML in sync.

## Run locally

No build step is required for the current static HTML pages.

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a modern browser.

For a more reliable local preview, serve the folder with any simple static file server.

## Notes

- This repository is a frontend project and visual experiment.
- Social sign-in artwork in the UI does not by itself mean OAuth authentication is configured.
- Do not add real passwords, API keys, or other secrets to committed files.
